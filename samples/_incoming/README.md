# Incoming sample projects

Place Plant 3D project folders (or at least `ProcessPower.dcf`) here when the client emails a new fixture.

Then:

1. Rename/move to `samples/<ClearProjectName>/`.
2. Add a short `README.md` in that folder.
3. Update `samples/README.md` and the related QA ticket (e.g. FB-001).

Do not commit `.dcf` files (gitignored).
